# WNC Surveillance Watch

The sourced public record of how surveillance technology came to Asheville and Western North Carolina: meetings, contracts, audit logs, and votes, every claim linked to a document you can check yourself.

**Live site: https://wncwatch.org**

Built with [Quartz](https://quartz.jzhao.xyz/). Content syncs from an editorial vault; the site builds and deploys via GitHub Actions on every push to main.

Corrections: use the site's Get Involved page with a link or a document. Corrections run with the same prominence as the original claim.
